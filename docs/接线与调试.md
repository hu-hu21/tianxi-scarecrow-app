# 接线与调试

## 1. 连接器总览

PCB 丝印与下表一一对应，插头方向以板边丝印和方焊盘（1 脚）为准。

| 连接器 | 位号 | 规格 | 用途 |

| J1 | 2×15P 2.54 | ESP32 DevKit 30Pin | 主控 |
| J2 | 1×5P 2.54 | WT41 雷达 | 5 V / GND / TX / RX / OUT |
| J3 | 1×6P 2.54 | DFPlayer Mini | VCC / RX / TX / SPK1 / SPK2 / GND |
| J4 | 1×3P 2.54 | SG90 舵机 | 5 V / GND / PWM |
| J5 | 2P 5.08 螺钉端子 | 12 V 输入 | 12 V+ / GND |
| J6 | 2P 5.08 螺钉端子 | 喇叭 | SPK+ / SPK− |
| J7 | 1×3P 2.54 | 红蓝灯带 | 12 V+ / 红灯− / 蓝灯− |
| J8 | 1×4P 2.54 | I2C 扩展 | 3V3 / GND / SDA / SCL |
| J9 | 1×2P 2.54 | 光敏电阻 | 3V3 / 分压点 |

## 3. 首次上电检查（按顺序）

1. **不接 12 V**，只插 USB：
   - 串口应打印 `=== Scarecrow Bird Deterrent v1 ===` 和 `[READY]`。
   - 板载蓝灯慢闪，状态 `IDLE`。
2. 万用表测 3V3 与 GND：3.25–3.35 V。
3. 接 12 V（先串 1 A 限流电源）：
   - 测 MP1584 输出 5.0–5.2 V；高于 5.5 V 立即断电。
   - 测 C1 两端 12 V 稳定，D2 不发热。
4. 接 DFPlayer（先不插喇叭）：串口 `test`，模块指示灯应闪，随后能听到轻微底噪。
5. 接喇叭：`test` 应有音乐，音量 26。
6. 接灯带：`test` 时红蓝交替爆闪，MOS 不烫。
7. 接舵机：`test` 时 30–150° 往返，无堵转异响。
8. 接雷达：手在 2–3 m 前晃动，串口 `status` 的 `pulses` 增长并触发。

## 4. 串口 CLI（115200 8N1）

| 命令 | 作用 |
|---|---|
| `status` | 打印状态、电池电压、昼夜、静音、脉冲计数、当前配置 |
| `test` | 立即执行一次驱赶（不受冷却限制） |
| `save` | 保存当前配置到 NVS |
| `reset` | 恢复默认配置并重启 |
| `vol N` | 设置白天音量 0–30 |
| `cool N` | 设置冷却时间（秒） |
| `quiet 0/1` | 关闭/开启静音时段 |

默认值：白天音量 26、夜间 16、灵敏度 3、窗口 2500 ms、冷却 60 s、时长 8–18 s、音轨 8 首、静音 22:00–06:00（默认关闭）。

## 5. Web 配置

- 设备上电即开热点（AP+STA 共存）：热点名 `Scarecrow-XXXX`（XXXX 为 MAC 低 16 位），密码 `scarecrow`，网关固定 `192.168.4.1`。
- 如果保存过路由器 SSID/密码，设备同时尝试连接路由器；连上后热点仍然保留，串口会打印 STA 的局域网 IP。
- 两种访问方式都可用：连设备热点打开 `http://192.168.4.1/`，或连同一路由器打开 `http://<设备局域网IP>/`。`192.168.4.1` 不是家里路由器的地址，电脑连着家里 Wi-Fi 时打不开它是正常的。
- 可改：白天/夜间音量、灵敏度、冷却、时长、音轨数、静音时段、光敏阈值。
- 保存后参数立即生效；Wi-Fi 凭据变更需重启，STA 连上后也可用 ArduinoOTA（主机名 `scarecrow`）。
- 热点常开比纯 STA 多约 20–30 mA 平均电流；太阳能余量紧张时，可把 `webBegin()` 改回仅 STA、失败再开 AP。

> 网页没有鉴权，仅建议在调试期开启，部署后把 Wi-Fi 密码设好并关闭 AP 回退（或改固件）。

## 6. 常见问题

| 现象 | 排查 |
|---|---|
| 上电无打印 | USB 线是否数据线；驱动是否安装；按住 BOOT 再点 EN |
| 雷达一直触发 | 灵敏度调到 4–5；避开风扇、窗帘、阳光直射；雷达与灯带电源分开走线 |
| 雷达完全不触发 | 测 J2-1 是否 5 V；OUT 是否有 3.3 V 跳变；确认 GPIO34 未被其他功能占用 |
| 没有声音 | DFPlayer 是否插卡（FAT32、MP3 文件夹）；RX 是否串 1 kΩ；喇叭是否接 SPK1/SPK2 |
| 声音断续/杂音 | 5 V 加 470 µF（板上 C5）；喇叭线与雷达线分开；电池电压是否过低 |
| 舵机抖动或复位 | 5 V 电流不足，舵机与 ESP32 分开供电或加大电容；共地必须可靠 |
| 灯带不亮 | 灯带共阳 12 V 是否接对；MOS 栅极是否有 3.3 V；R3/R5 是否 100 Ω |
| 电池电压不准 | 改 `VBAT_R_TOP_KOHM` / `VBAT_R_BOT_KOHM`；用万用表对比后修正 |
| 夜里还在叫 | 光敏阈值 `ldrNightThreshold` 调大；或开启静音时段并确保 NTP 对时 |
| 连不上 Wi-Fi | 2.4 GHz only；SSID 不要带中文；信号弱时先用 AP 模式改参数 |
| 浏览器一直转圈、打不开 192.168.4.1 | 电脑/手机还连着家里路由器。`192.168.4.1` 只在设备热点网络内有效：先连 `Scarecrow-XXXX`，`ipconfig` 应显示 `192.168.4.x`。若设备已配置 STA，改用串口启动日志打印的局域网 IP，或运行 `python tools/find_device.py` 扫描 |
| 网页一直显示“读取中…” | 先直接打开 `http://192.168.4.1/api/status`：返回 JSON 说明设备正常，刷新页面或用无痕窗口；返回 404 说明固件较旧，重刷当前固件；返回内容含 `nan`/`inf` 或不是 JSON，重刷 1.2.0 及以上。浏览器代理/VPN 也会拦截局域网请求，需关闭 |

## 7. 户外部署

- 地插入土 ≥ 350 mm，回填夯实；松软地面加地钉或混凝土墩。
- 立柱垂直度 ≤ 2°，云台朝向主要来鸟方向。
- 电控盒置于立柱 0.9–1.0 m 高处，出线孔朝下并打防水胶。
- 太阳能板朝南（北半球）倾斜 30°–40°，避免被立柱遮挡。
- 冬季低温：铅酸容量下降明显，低电阈值可上调 0.3 V。
- 每 3 个月检查：紧固件、线缆护套、灯带透光罩、喇叭防雨罩。
